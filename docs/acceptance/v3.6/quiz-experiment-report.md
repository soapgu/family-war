# v3.6 Phase 1.5 答题比赛统计实验报告

## 1. 结论

三批公平实验共运行 60 场比赛：算术 30 场、默写 30 场。Browser A/B 总比赛胜场为 30:30，人类累计回合为 228:228；爸爸/妈妈总比赛胜场同样为 30:30。机器人没有赢得公平比赛，在第一批默写实验中取得 1 个回合。

这些结果说明当前本地 Chromium、双独立 Browser Context 和真实 Socket.IO 链路下，Browser 与角色维度的总体结果接近均衡。样本量仍然有限，本报告只作为调度分布参考，不作为公网环境公平性的统计证明或发布门禁。

## 2. 实验口径

- 每批算术、默写各运行 10 场，均采用 5 分制、5 秒题目时限和 2.5 秒机器人延迟。
- A/B 每场使用新的独立 Browser Context 和 Socket.IO 连接，爸爸/妈妈角色逐场交换。
- 双方先准备答案，再由各自页面按同一个未来目标时间提交；默写答案只来自公开的 TTS 文本。
- 比赛胜率超出 30%-70%、人类回合胜率超出 40%-60% 或机器人赢得公平比赛时只产生观察警告；流程不一致仍属于硬失败。
- 第一、二批的自动报告已被后续运行覆盖，只保留下表中的汇总数据；第三批的逐场数据仍保存在当前 Git 忽略的 JSON 报告中。
