# v3.6.0 版本发布报告

执行时间：2026-08-08

## 发布范围

v3.6.0 完成游戏端 E2E 回归基线与服务端房间及对局生命周期治理：

- 建立三种游戏模式的 Playwright E2E 回归基线（Phase 1）；
- 建立服务端生命周期测试基线，冻结状态/权限矩阵（2a/2b）；
- 实现带 gameId 防护的统一对局清理入口（2c）；
- 修复 LIFE-001（参赛者离开/断线取消整场）和 LIFE-002（认输校验参赛者）（2d/2e）；
- 收敛所有游戏事件权限与冻结错误文案（2f）；
- 治理终局离开与重赛授权（2g）；
- 补齐幂等与竞态基线（2h）；
- 增加生命周期诊断日志与脱敏修复（2i）。

本版本不新增游戏模式，不引入数据库，不扩展平台用户认证。

详细证据见 `docs/acceptance/v3.6/phase-2-report.md`。

## 升级说明

- Socket.IO 事件与 Payload 保持兼容，取消消息继续使用 `{ message }`；
- 部分 `game:error` 文案收敛为冻结文案（如"你不在这个房间中"），客户端纯透传显示；
- 新增 `lifecycle.js` 为服务端内部模块，不暴露新 Socket 事件；
- RPS 断线重连行为保留 `@lifecycle-issue`，不恢复原对局/角色（设计冻结）；
- 本版本无数据库迁移或数据格式转换。

## 发布结论

版本号、代码、自动化、预发布部署、回滚说明和发布文档一致，满足 v3.6.0 发布条件。
正式环境步骤因没有独立正式环境而明确跳过，不将本机预发布描述为正式环境。
